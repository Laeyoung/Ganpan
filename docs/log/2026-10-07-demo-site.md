# Conceptual demo site + demo videos

- **Date:** 2026-10-07
- **Issue / PR:** — / (this branch: `feat/demo-site`)
- **Type:** docs (marketing asset; nothing shipped to installed users)
- **Version:** unchanged (no plugin/engine/CLI change)

## What changed
- `demo/index.html` is a single-file, dependency-free **simulation** of Ganpan.
  - It shows a GitHub-style board with one column per `status:*` label, a terminal running `/ganpan:run-all`, the four lane agents plus the human, and a GitHub activity feed.
  - A scripted scenario plays out over 8 chapters: backlog, triage (including a `blocked` issue), claim/worktree/PR, review with a human merge and then with `reviewer.autoMerge`, a `needs-decision` gate with a trusted answer and a follow-up issue, a QA fail followed by rework, and unblock. It ends on a summary card ("PRs approved by agents: 0").
  - It has Korean and English captions, play/pause/speed/restart controls, and `?autoplay=1` for unattended recording.
- `demo/ganpan-demo-{ko,en}.mp4` are 1920×1080 recordings, about 86 s each and about 5 MB each.
- `demo/record.cjs` re-records both videos (Playwright + ffmpeg). `demo/README.md` documents the parameters and the scenario.

## Why
The README explains the label state machine in text. A short visual walk-through shows the lanes, the human gates, and the "agents never approve" rule much faster.

## Key decisions
- **Scripted, not live.** The page never touches GitHub, and an always-visible "SIMULATION" badge says so. Scenario facts mirror the real contract: label names from `assets/labels.yml`, `claim.sh`/`reclaim.sh`/`unblock-check.sh`/`auto-merge.sh`, bot-only markers (`merge-requested`, `decision-requested`/`decision-resolved`, `followup-created`), `Refs #n`, QA-only close, and trusted (write+) answers.
- **Human choices are clickable, but the scenario stays fixed.** Picking the non-suggested option prints a "(demo) continues down the suggested path" note instead of branching. Branching would multiply the script for no conceptual gain.
- **Videos are kept small (CRF 26, `-tune animation`).** The marketplace clones this repo for every install, so 22 MB of video at CRF 20 was cut to about 10 MB total with no visible loss of text sharpness.
- **Videos are recorded at a 1600×900 viewport and upscaled to 1080p.** Playwright's video ignores `deviceScaleFactor`, and a 1920-wide viewport left the board sparse with small text.
- **Location is `demo/`.** It is not a skill directory, so `npx skills` discovery is unaffected, and it is outside `package.json` `files`, so the npx package does not grow.

## Alternatives considered (not chosen)
- **Embedding the videos via a GitHub release asset instead of committing them:** this keeps clones lean, but it makes the demo depend on a release step. It remains an option if the videos are re-recorded often.
- **Frame-by-frame deterministic capture (screenshots per tick):** pixel-perfect, but it needs a virtual clock for the CSS/WAAPI animations. The real-time recording is already clean.
